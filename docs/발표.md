# 지하로 — 발표 구성안

COM's 해커톤 2026 · 주제: 전쟁 · 혼자 참가

슬라이드 원본은 `slides/index.html`, 만든 파일은 `web/slides/index.html`(서비스 주소 `/slides/`), PDF는 `docs/발표.pdf`다. 이 문서의 '화면'은 슬라이드에 적힌 글 그대로이고, '말할 것'은 발표자 메모(N 키)에 들어간 단서다. 문장으로 외우지 않고 단서를 보며 자기 말로 한다(코드는 발표자가 직접 설명해야 하는 규칙).

- 발표 시간은 모른다. 본 발표 약 6분(350초) + 라이브 시연 약 2분으로 짠다. 3분만 받으면 맨 아래 '3분 버전'을 쓴다.
- 평가 기준(각 20점): 주제 적합성, 창의성, 기술성, 완성도, 실용성. 동점이면 완성도, 그다음 주제 적합성.
- 근거 문서: `README.md`, `docs/계획서.md`, `docs/코드설명.md`, `docs/data-check.md`, `docs/roads-shelters-check.md`, `docs/plan.md`, 코드.
- 스크린샷은 모두 `docs/screens/` 안의 파일이다. `slides-*.jpg`는 2026-11-11 라이브 사이트에서 어두운 화면으로 찍었다(시연 조작 칸은 숨김).
- 화면 문장 규칙: 제목은 숫자·장소·행동이 든 사실 한 가지. 구호, 대칭 문장, 비유, 강조어, 번호 카드, 머리 위 작은 이름표를 쓰지 않는다.

  - 비용 = 길이 × 가중치: 지하 1, 지상·교량 1000
  - 지하로만 가는 길이 있으면 저절로 그 길, 없으면 지상 구간이 가장 짧은 길
  - 옥수→압구정: 3호선은 동호대교(교량)로 건넘 → 지하 우선이면 24.0km 돌아감

  - 대안은 누를 때만 바뀜, 기본은 지하 우선
- 시간: 35초
- 평가: 창의성, 기술성
- 근거: README '대안 카드', `web/js/router.js` 23행 `ALT = { exposedW: 15, minSavedFrac: 0.2, minSavedMin: 30, maxExtraExposedM: 2000 }`(336행: 20% 미만이면서 30분 미만이면 대안 없음), 스크린샷 카드 "지상 1.2km 걸으면 22km 짧아요 · 약 6시간 단축", data-check A7(3호선 옥수–압구정 동호대교)

## 11. 코드 ① 지하 판정

- 화면:
  - 제목 "tunnel 태그가 있는 선로만 지하로 본다"
  - 코드 `scripts/build_graph.py` 298–304행 (원문 그대로)

    ```python
    def classify(tags):
        t, b = tags.get("tunnel"), tags.get("bridge")
        if t and t != "no":
            return "tunnel"
        if b and b != "no":
            return "bridge"
        return "ground"  # layer<0, covered=yes도 지상으로 둔다
    ```

  - "layer<0은 지하로 치지 않는다"
  - "경부선 금정~수원 약 16km는 OSM에서 layer=-1이지만 실제로는 지상이다"
  - 작은 줄 "경인일보: 금정~군포~당정 4.84km 지상 운행 (docs/data-check.md 4.4절)"
- 말할 것:
  - classify 하나가 지하·교량·지상 판정 전부
  - tunnel 태그(no 아님) → 지하, bridge → 교량, 나머지 지상
  - layer=-1만 있는 선로는 지상: 경부선 금정~수원, 선로 4줄
  - 전국에서 layer<0이고 tunnel 없는 본선 90.1km 중 63.6km가 이 경부선
  - 한계: 동대구처럼 역 건물 밑 선로를 tunnel로 그린 곳은 지하로 계산됨
- 시간: 35초
- 평가: 기술성 (규칙 대응: 발표자가 코드를 직접 설명)

## 12. 코드 ② 경로 탐색

  - 101: 막힌 간선은 건너뜀 → '앞이 막힘'도 같은 함수를 다시 부름
  - 질문 대비: 대안은 지상 가중치 15로 다시 탐색 (23행 ALT), 다익스트라 전체는 71–108행
